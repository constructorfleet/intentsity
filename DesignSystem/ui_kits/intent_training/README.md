# Intent Trainer — UI kit

Full-screen recreation of the intent-training editor. Reviewers open real captured conversations and edit tool-call arguments and assistant responses to become golden examples for LLM fine-tuning.

**Files**
- `index.html` — mounts the app
- `Trainer.jsx` — full screen composed from Sidebar, Toolbar, ConversationTurn, ToolInvocation, Textarea, KeyValue, StatCell
