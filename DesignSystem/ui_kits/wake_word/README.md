# Wake Word Annotator — UI kit

Full-screen recreation of the wake-word review workspace. Reviewers cycle through candidate clips, listen to the audio, and apply one of five labels (TP/TN/FP/FN/Background). Keyboard-first: `1`–`5` label, `Space` play, `J`/`K` navigate.

**Files**
- `index.html` — mounts the app
- `Annotator.jsx` — full screen composed from Sidebar, Toolbar, Waveform, LabelChip, StatCell, Card
